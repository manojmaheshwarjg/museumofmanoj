# Museum of Manoj

A personal site you walk through like a museum.
Walk up 26th Avenue, pick a tour at the ticket booth, and a doodle guide takes you inside.
Twelve stops, one life, from Chennai to New York.

**Stack:** Vite, vanilla JavaScript, three.js, GSAP with ScrollTrigger, Lenis and rough.js, on Vercel (a Vercel function and Upstash Redis keep the visitor count).
